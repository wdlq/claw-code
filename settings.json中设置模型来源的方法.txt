● ANTHROPIC_DEFAULT_OPUS_MODEL 不是 claw-code 支持的环境变量。claw-code 使用的是
   ANTHROPIC_MODEL。

  正确的配置：

  {
    "env": {
      "ANTHROPIC_MODEL": "mimo-v2.5-pro",
      "ANTHROPIC_AUTH_TOKEN": "XXXXXXX",
      "ANTHROPIC_BASE_URL": "https://token-plan-cn.xiaomimimo.com/anthropic"
    },
    "hooks": {
      "PreToolUse": ["python .claw/hooks/keyword_restorer.py"],
      "PostToolUse": ["python .claw/hooks/keyword_redactor.py"]
    }
  }

  claw-code 支持的环境变量：
  ┌──────────────────────┬──────────────┐
  │       环境变量       │     用途     │
  ├──────────────────────┼──────────────┤
  │ ANTHROPIC_API_KEY    │ API Key      │
  ├──────────────────────┼──────────────┤
  │ ANTHROPIC_AUTH_TOKEN │ Bearer Token │
  ├──────────────────────┼──────────────┤
  │ ANTHROPIC_BASE_URL   │ API 端点     │
  ├──────────────────────┼──────────────┤
  │ ANTHROPIC_MODEL      │ 模型名称     │
  └──────────────────────┴──────────────┘
  ANTHROPIC_DEFAULT_OPUS_MODEL、ANTHROPIC_DEFAULT_SONNET_MODEL 等是官方 Claude 
  Code 特有的，claw-code 不支持。

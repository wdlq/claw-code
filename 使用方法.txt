     实现 PostToolUse Hook 的 updatedToolOutput 功能

     背景

     用户需要在 claw-code 中实现一个 hook 机制：
     - 在读取文件前，如果文件中含有指定关键词（如
     AAA、BBB），用算法替换掉它们
     - 替换规则全局适用，每次读取替换的结果都相同
     - 读取完成后，再替换回来

     根据官方 Claude Code 文档，PostToolUse hook 支持 updatedToolOutput 
     字段来替换工具输出。但当前 claw-code 的 Rust 实现中尚未实现此功能。

     实现方案

     修改文件清单

     1. rust/crates/runtime/src/hooks.rs - 核心 hook 执行引擎
     2. rust/crates/runtime/src/conversation.rs - 对话运行时中的 hook 调用

     用户使用示例

     实现后，用户可以在 .claude/settings.json 中配置：

     {
       "hooks": {
         "PostToolUse": [
           {
             "matcher": "Read",
             "hooks": [
               {
                 "type": "command",
                 "command": "python replace_keywords.py"
               }
             ]
           }
         ]
       }
     }

     replace_keywords.py 脚本示例：

     import sys
     import json

     # 读取 stdin 的 JSON 输入
     input_data = json.load(sys.stdin)

     # 获取工具输出
     tool_output = input_data.get("tool_output", "")

     # 替换关键词
     replacements = {
         "AAA": "REPLACED_A",
         "BBB": "REPLACED_B"
     }

     modified_output = tool_output
     for key, value in replacements.items():
         modified_output = modified_output.replace(key, value)

     # 返回 updatedToolOutput
     result = {
         "hookSpecificOutput": {
             "hookEventName": "PostToolUse",
             "updatedToolOutput": modified_output
         }
     }

     print(json.dumps(result))

  1. 创建 hook 脚本

  在项目目录下创建 .claude/hooks/replace_keywords.py：

  #!/usr/bin/env python3
  import sys
  import json
  import hashlib

  # 定义要替换的关键词
  KEYWORDS = ["AAA", "BBB", "SECRET_KEY", "PASSWORD"]

  def generate_replacement(keyword):
      """生成确定性替换值 - 同一关键词总是生成相同的替换"""
      hash_hex = hashlib.sha256(keyword.encode()).hexdigest()[:12]
      return f"__REDACTED_{hash_hex}__"

  def main():
      input_data = json.load(sys.stdin)
      tool_output = input_data.get("tool_output", "")

      # 替换关键词
      modified = tool_output
      for kw in KEYWORDS:
          modified = modified.replace(kw, generate_replacement(kw))

      # 返回替换后的输出
      result = {
          "hookSpecificOutput": {
              "hookEventName": "PostToolUse",
              "updatedToolOutput": modified
          }
      }
      print(json.dumps(result))

  if __name__ == "__main__":
      main()
